### About me

I'm a **React Native Engineer** and **Full-Stack Developer** who likes building products that feel inevitable once you use them. My current focus is **real-time mobile systems** — SDK integrations, push and VoIP workflows, and operational dashboards that have to stay in sync across every device on the floor.

I'm currently at **CometChat**, contributing production fixes and features to the open-source React Native UI Kit, debugging live SDK integrations across FCM / APNs / VoIP, and turning developer pain into shipped releases. Outside of that I'm building **PlotVista**, a real-time real-estate operations platform used to run an entire site from a phone.

I work in an **AI-augmented** loop — Cursor and structured context engineering are part of how I plan, ship, and debug — and I care deeply about clean APIs, predictable state, and the boring details that decide whether a product survives day three.
